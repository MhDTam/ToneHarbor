# ToneHarbor 1.1.4 — Windows x64

English · [⁧العربية⁩](#العربية)

## Download and run

1. Download **ToneHarbor-1.1.4-windows-x64.zip** from the assets below.
2. Extract the complete archive to a writable folder.
3. Run **ToneHarbor.exe**. Keep the DLLs and `data/` directory beside it.

This is an unsigned portable Windows x64 build. No Flutter SDK or development tools are required.

**FFmpeg is a separate dependency for waveforms, audio editing and conversion.** Install an FFmpeg Windows build on `PATH`, or place `ffmpeg.exe` in the `tools/` folder beside ToneHarbor.exe. The executable is not bundled in this release. [FFmpeg downloads](https://ffmpeg.org/download.html) lists Windows build providers. The included documentation explains the required audio encoders.

The app also needs Microsoft's Visual C++ v14 x64 runtime. If it is missing, use the [official Microsoft download](https://aka.ms/vc14/vc_redist.x64.exe).

## Included

- Desktop Home, Library, playlists, folders and settings.
- Full and frameless mini players, queue, repeat modes, sleep timer and editable shortcuts.
- Five themes, custom artwork and English/Arabic/Persian interfaces.
- Batch conversion and an audio editor with real waveform selection, preview, undo/redo and audio effects.
- Windows Open with integration and single-instance activation.
- FLAC export compatibility fix for newer FFmpeg builds.
- Safe, application-scoped cache cleanup and reliable cancellation of pending editor previews.
- Safe, application-scoped cache cleanup and reliable cancellation of pending editor previews.

The project is licensed under MIT. Dependency notices and Flutter runtime notices are included. No user media, preferences or library databases are bundled.
