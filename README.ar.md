# ToneHarbor

[English](README.md) · ⁧العربية⁩

⁧مشغّل صوتيات ومحوّل ملفات ومحرّر صوت لسطح مكتب ويندوز، مبني باستخدام Flutter ومتاح كمصدر مفتوح بترخيص MIT.⁩

![ToneHarbor Home](docs/images/home.png)

## ⁧المزايا⁩

- ⁧مكتبة محلية مع البحث والفرز والتجميع حسب الألبوم والفنان والمجلد، والمفضلة وقوائم التشغيل.⁩

- ⁧تحديد متعدد باستخدام Ctrl وShift، والضغط المطوّل والسحب. الإزالة من المكتبة وحذف الملف الأصلي عمليتان منفصلتان.⁩

- ⁧قائمة انتظار، مؤقّت إيقاف، سرعة تشغيل قابلة للتغيير، وأوضاع تكرار يمكن تمييزها.⁩

- ⁧مشغّل كامل ومشغّل مصغّر بدون إطار، مع الظهور فوق النوافذ والتحكم بالشفافية.⁩

- ⁧موجات صوتية حقيقية من الملف، بنوافذ زمنية محدودة لتقليل الاستهلاك.⁩

- ⁧تحويل متعدد من الفيديو إلى الصوت وتصدير بعدة صيغ، مع عرض التقدّم وإمكانية الإلغاء.⁩

- ⁧محرّر صوت يتضمن القص الدقيق، التراجع والإعادة، المعاينة، موازن الصوت، تسوية مستوى الصوت، تقليل الضجيج، التلاشي والمؤثرات المكانية.⁩

- ⁧خمسة ثيمات، صور قابلة للتخصيص، واختصارات لوحة مفاتيح قابلة للتعديل.⁩

- ⁧واجهات بالعربية والإنكليزية والفارسية، وتخطيطات للنوافذ الصغيرة والشاشات العريضة.⁩

- ⁧تكامل مع قائمة «فتح باستخدام» في ويندوز، وفتح الملفات ضمن نسخة واحدة من البرنامج.⁩

## ⁧المتطلبات والصيغ⁩

⁧المنصة المعتمدة حالياً هي Windows x64. مشاريع المنصات الأخرى غير مرفقة، حتى لو احتوت الشيفرة المشتركة على محوّلات خاصة بها.⁩

⁧يعتمد التشغيل على ترميزات ويندوز ومحرك الصوت. يتعرّف البرنامج على امتدادات MP3 وWAV وFLAC وM4A/AAC وOGG وOPUS وWMA؛ لكن الامتداد وحده لا يضمن تشغيل كل ترميز داخل الملف.⁩

⁧يلزم FFmpeg للتحويل والتحرير واستخراج الموجة الصوتية. ثبّت نسخة تتضمن مشفّرات MP3 وAAC وFLAC وVorbis وOpus، وأضفها إلى PATH أو ضع ffmpeg.exe داخل tools/. راجع [دليل الأدوات](tools/README.md).⁩

## ⁧البناء من المصدر⁩

⁧ثبّت [متطلبات Flutter على ويندوز](https://docs.flutter.dev/platform-integration/windows/setup)، بما فيها Visual Studio مع حزمة Desktop development with C++. الإصدار الذي اجتاز الفحص المحلي هو Flutter 3.47.5 مع Dart 3.13.4، والمذكور في [.flutter-version](.flutter-version).⁩

```powershell
git clone https://github.com/MhDTam/ToneHarbor.git
cd ToneHarbor
flutter pub get --enforce-lockfile
flutter analyze --no-pub
flutter test --no-pub
flutter run -d windows --no-pub
```

⁧لبناء نسخة ويندوز محمولة:⁩

```powershell
pwsh -File tool/build_windows.ps1
```

⁧تظهر النتيجة داخل dist/ToneHarbor/. احتفظ بالملف التنفيذي وملفات DLL ومجلد data معاً. يضيف السكربت إشعارات التراخيص، ولا يضمّن FFmpeg؛ يمكن استخدامه عبر PATH أو إضافته منفصلاً مع الالتزام بترخيص نسخته.⁩

## ⁧محرّر الصوت⁩

![ToneHarbor Audio Editor](docs/images/audio-editor.png)

⁧يصدّر المحرّر إلى ملف جديد ويحمي ملفات الإخراج الموجودة. تعالج المعاينة حتى 30 ثانية من الصوت الناتج، ولا تستبدل قائمة تشغيل المشغّل الرئيسي.⁩

⁧تعرض الموجة شدة الصوت عبر الزمن، وليست محلّلاً حياً للترددات. الصور المعروضة مولّدة من واجهات البرنامج باستخدام بيانات اختبار وموجة توضيحية، ولا تتضمن مكتبة مستخدم شخصية.⁩
