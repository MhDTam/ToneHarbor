# Security

Security fixes target the latest source revision. Older portable builds do not have a promised support lifecycle.

Use GitHub's **Report a vulnerability** feature if private reporting is enabled. Otherwise, open an issue asking for a private contact channel without disclosing exploit details or uploading malicious media publicly.

Include the affected revision, Windows version, reproduction steps and impact. Remove private paths, tokens and unrelated media. Decoder vulnerabilities may also need reporting to FFmpeg or the relevant Windows codec vendor.

Routine interface/playback problems belong in the normal issue tracker.
